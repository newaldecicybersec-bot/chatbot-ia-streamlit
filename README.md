# 🤖 Chatbot com IA — Streamlit + OpenAI

Projeto do curso de Python IA (módulo 03. Python AI). Um chatbot web completo com memória de conversa, feito com **Streamlit** e **OpenAI**.

## ✨ Funcionalidades

- 💬 Campo de mensagem em tempo real (`st.chat_input`)
- 🧠 Memória de conversa (a IA lembra do que você falou antes)
- 🎨 Interface web limpa com Streamlit
- ⚡ Respostas com GPT-4o-mini

## 🚀 Como rodar

```bash
pip install -r requirements.txt
export OPENAI_API_KEY=sua_chave_aqui
streamlit run codigo.py
```

## 📚 O que eu aprendi aqui

- Integração Python com API da OpenAI
- Estado de sessão no Streamlit (`st.session_state`)
- Histórico de mensagens no formato role/content
- Construção de interfaces conversacionais
